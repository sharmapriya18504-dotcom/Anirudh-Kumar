# Anirudh Kumar – Digital Marketing Expert & SEO Specialist (1:1 Exact Website Clone)

An exact 1:1, pixel-perfect, fully responsive recreation of [https://anirudhkumarseo.netlify.app/](https://anirudhkumarseo.netlify.app/) built using **React**, **Vite**, **React Router**, and modern CSS.

---

## 🌟 Overview & Recreated Features

Every section, layout, page, visual asset, animation, and responsive behavior has been rebuilt to match the original website exactly:

### 1. Branding & Identity
- **Name:** Anirudh Kumar
- **Headline:** ANIRUDH KUMAR – BEST SEO EXPERT & DIGITAL MARKETING CONSULTANT IN LUCKNOW
- **Tagline & Bio:** All original Hindi/English (Hinglish) copy preserved word-for-word.
- **Original Assets:** High-resolution persona portraits (`Untitled design (12).png`, `anik.png`), service graphics (`service-seo.png`, `service-smm.png`, `service-ads.png`, `service-web.png`, `service-kanpur.png`, `service-consulting.png`), favicon, and logo.
- **Typography & Colors:** Google Fonts (`Bebas Neue` and `Plus Jakarta Sans`), custom brand gradients, dark theme `#06060F`, light theme support, neon glowing accents, and Bootstrap Icons.

### 2. Pages & Routing
Full client-side routing with `react-router-dom`:
- `/` – **Home Page** (Hero, Services, About, Why Choose Us, Results/Counters, Process, Portfolio, Testimonials, Pricing, Locations, Blog Preview, FAQ Accordion, Free SEO Audit Contact Form)
- `/services` – **Services Overview**
- `/seo-lucknow` – **SEO Services in Lucknow**
- `/smm-lucknow` – **Social Media Marketing**
- `/ads-lucknow` – **Google & Meta Ads**
- `/web-dev-lucknow` – **Website Development**
- `/marketing-kanpur` – **Digital Marketing Kanpur**
- `/seo-consultant` – **SEO Consultant**
- `/about` – **My Story / About Anirudh Kumar**
- `/why-choose-us` – **Why Choose Us**
- `/results` – **Results & Proof**
- `/testimonials` – **Client Reviews & Ratings**
- `/case-studies` – **Growth Case Studies**
- `/pricing` – **Transparent Pricing Packages**
- `/blog` – **Interactive Marketing Blog** (Dynamic real-time keyword search, category filter pills, responsive grid, pagination)
- `/blog-post?post=:slug` – **Dynamic Article Reader** (Table of contents generation, author badge, article content, share buttons, CTA banner, and related articles)
- `/contact` – **Contact Page & Free SEO Audit**

### 3. Interactive Behaviors & Animations
- **Animated Preloader:** Staggered character animation for "Anirudh Kumar" with a 0% → 100% counter and animated progress bar.
- **Typewriter Effect:** Animated cycling between `"BEST SEO EXPERT"` and `"DIGITAL MARKETER"` in the hero title with typing, pausing, and backspacing.
- **Dark / Light Theme Switcher:** Fully functional theme toggle with local storage persistence and sun/moon icon toggle.
- **Sticky Navbar & Smooth Scrolling:** Adds blurred background on scroll; smooth in-page anchor navigation.
- **Mobile Hamburger Navigation:** Sliding full-screen drawer with close button and instant link transitions.
- **Animated Stat Counters:** Numbers count up from 0 to target (200+, 5+, 87) when entering the viewport.
- **3D Card Tilt Effect:** Interactive mouse-following 3D perspective tilt on service cards.
- **Scroll Reveal & Skill Bars:** Section animations and skill fill effects on scroll.
- **Conic-Gradient Back-To-Top Button:** Circular progress indicator with live percentage and smooth scroll to top.
- **Top Scroll Progress Bar:** Gradient bar fixed at top tracking reading progress.
- **Smooth Mouse Follower:** Cursor glow follower that expands on interactive hover states.
- **Interactive FAQ Accordion:** Expanding and collapsing answers with animated chevron icons.
- **Contact Form Feedback:** Submitting the form changes the CTA to `"✅ Submitted! 24 hrs mein reply milega."` with green background state for 4 seconds.
- **Floating WhatsApp Button:** Direct chat button with pre-filled greeting.

## 🚀 Running the Project Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+ recommended)
- `npm`

### Installation
```bash
# Install dependencies
npm install
```

### Development Server
```bash
# Start Vite development server
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
